# Exemplar Learning Dossier

> 用途：在写作前**强制学习** target venue 已发表的 2-3 篇 strong example，产出可执行的写作约束。
>
> 解决的问题：写完才发现"这本刊不是这么写的"——venue mismatch 是中文 LIS 与英文应用刊投稿被拒的高频原因。
>
> 配套产出：`target_scene_norms.md` 与 `style_profile.md`。本文件是这两者的母文件。

## 实证背书

- PaperSpine 设计：研究阶段必须产出 exemplar learning dossier + style profile，否则不让写作
- Alvesson & Sandberg (2020) problematizing review：写作必须明确"在什么对话中说话"

## 选择 exemplar 的规则

### 规则 1 · 真实 target venue

只能选**目标期刊** / **目标会议**最近 2-3 年发表的论文。**不能用其他刊或 preprint 替代**。理由：审稿人和编辑就是从这个 pool 里来的，他们对"什么样算合格"有隐性 prior。

### 规则 2 · 三类各选一篇

| 类型 | 数量 | 角色 |
|---|---|---|
| 同题材近邻（与本文研究问题最像）| 1 | 学论证套路 |
| 同方法近邻（与本文方法最像但题材不同）| 1 | 学方法节呈现 |
| 同栏目顶配（与本文同栏目获奖 / 高引）| 1 | 学叙事顶配水准 |

如果某类找不到合适 exemplar → 在本文件显式标记 "无合适 exemplar"，并解释原因。

### 规则 3 · 必须是 strong example

不要选刚发表评分中等的；要选：
- 高被引（领域水位之上）
- 编辑特别推荐
- 获奖论文
- 同行内部公认 "教科书级"

## 跨 exemplar 综合

### Target Scene Norms（产出 → `target_scene_norms.md`）

| 维度 | 该 venue 的隐性规范 |
|---|---|
| Introduction 长度 | ≈ X 页 / Y 段 |
| Contribution sentence 形式 | 显式列表 / 嵌入式 / 不出现 |
| Related Work 位置 | §2 独立 / 与 §1 合并 / 散落各章 |
| Method 详略程度 | 细节级 / 摘要级 |
| Result 呈现风格 | 表 + 图均衡 / 偏表 / 偏图 / 偏文字 |
| Discussion 落脚 | 政策含义 / 理论含义 / 工程含义 |
| 文献数量典型范围 | X-Y 条 |
| 中文 / 英文引用比例 | (若中文期刊) X% |
| 摘要长度与结构 | 结构化（目的/方法/结果/结论）/ 段落 |
| 关键词数量 | 3-5 / 5-8 |
| 图表数量典型范围 | X-Y |
| 是否含 limitation 节 | 必有 / 可选 / 不要 |
| 投稿格式偏好 | LaTeX / Word / 双模板 |

## 反向 audit · 写作前自检

写完 introduction 第一稿后立刻对照本文件检查：

- [ ] 我的 contribution sentence 形式与 venue norm 一致？
- [ ] 我的 introduction 长度在 venue 典型范围？
- [ ] 我的 related work 位置选择与 venue 默认一致（如不一致，是否有充足理由）？
- [ ] 我的句长 / 段落长度与 style profile 接近？
- [ ] 我的首人称 we 用法符合 venue 习惯？

任一不一致 → 必须**显式决定**：照 venue 改 / 故意偏离（写明原因）。

## 不允许出现的"借口"

- "我没找到 3 篇近邻 exemplar"——花 1 小时找；找不到说明 venue 不对，应换 venue
- "exemplar 太老（5+ 年）"——找新的；老 exemplar 说明 venue 不再关心此类
- "exemplar 的方法跟我太不一样"——选另一篇；说明可能 method 不 fit venue
- "我之前已经熟悉这本刊的风格"——熟悉不等于 audit；本文件是结构化产出，凭印象不行
