# Venue Format Standards Gate · 按刊格式与体例核对

> 用途：投稿（或改投）前，拿目标刊的 `venue_profiles/<刊名>.md` 作基准，对稿件做一次**纯格式/体例**的硬核对。这是 `integrity_gate`（内容真实性）之外、专治"低级格式错误"的独立 gate。
>
> 解决的问题：内容再好，摘要多一个逗号、参考文献体例不对、缺中图分类号、双语缺失——编辑部初审就会形成"治学态度不严谨"的印象，甚至直接退稿。PaperForge 此前没有专门的"按刊格式 gate"。
>
> 触发时机：① 投稿前最后一关（在 `revision_gate` 之后）；② 改投他刊时（换刊就要重跑，因为体例随刊变）。

## 实证背书

- 退稿案例（2026-06，《图书情报工作》）审稿意见第 8 条：摘要中"…风险并非单纯技术问题…"多打一个逗号等低级错误被编辑部点名——这类问题 100% 可被本 gate 拦截。
- 设计来源：`awesome-journal-skills` 把"table formatting standards / 格式标准"单列成独立 skill，证明格式核对值得从内容审查里拆出来单独做。

## 前置条件

1. 目标刊已有 `venue_profiles/<刊名>.md`（无则先建档）
2. 稿件已过 `revision_gate`（内容已定稿，本 gate 只动格式）

## 核对项（逐项 PASS / FAIL，FAIL 必须列出具体位置）

### A · 摘要

- [ ] 摘要**结构**与本刊一致（结构化标签如 `[目的/意义][方法/过程][结果/结论]` 是否齐全且顺序正确；或段落式）
- [ ] 摘要**字数**在本刊区间内
- [ ] 人称符合要求（如教育类刊要求第三人称、禁用"本文"）
- [ ] 中英文摘要都在（若本刊要求）且语义对应
- [ ] 摘要内**无多余/缺失标点**（逐句扫一遍中文标点：，。；：""）

### B · 题名 / 关键词 / 分类号

- [ ] 中文题名字数 ≤ 本刊上限
- [ ] 英文题名存在且与中文对应（若要求）
- [ ] 关键词数量在区间内、中英文对应
- [ ] 中图分类号存在、版本正确；跨学科是否需两个

### C · 正文格式

- [ ] 标题层级编号风格与本刊一致（阿拉伯 `1 / 1.1` vs 中文 `一 /（一）`）
- [ ] 缩写**首次出现处给全称**（GenAI / AI4S / SOR / MAXQDA 等）
- [ ] 图、表均有编号与题注；图表编号连续无跳号
- [ ] 图表题注双语（若本刊要求）
- [ ] 表格无异常跨页、图片清晰可辨
- [ ] 字数在本刊区间内

### D · 参考文献与引用

- [ ] 参考文献体例与本刊一致（GB/T 7714 版本 / 注释体例）
- [ ] 文中引用标注方式正确（上标方括号 / 著者-年 / 脚注）
- [ ] **正文每个引用都有对应文后条目**，反之亦然（查空引用 `[][][]`、孤儿条目）
- [ ] 参考文献条数 ≥ 本刊最低要求
- [ ] 各条目要素完整（作者/题名/来源/年/卷期/页码/DOI 或网址+访问日期）

### E · 投稿要件

- [ ] 作者简介 / 通讯作者 / 作者贡献说明 / 基金项目（按本刊必填项）
- [ ] 投稿文件格式正确（Word / LaTeX / 本刊模板）
- [ ] 补充材料（附录、访谈提纲、完整编码表）按本刊要求另附或转在线

## 输出

- 一份 PASS/FAIL 清单，FAIL 项标注稿件具体位置（文件/页/段）
- 全部 PASS 方可投递；任一 FAIL → 修正后复跑本 gate
- 改投他刊 → 切换 `venue_profiles` 基准，整表重跑

- YYYY-MM-DD · 复跑，全部 PASS，准予投递
