# Journal Match · 选刊匹配与重投阶梯

> 用途：从论文（或摘要 + 少量事实）出发，产出一份**分层的目标刊清单**（reach / match / safe 三档）和一条**退稿后重投阶梯**（resubmission ladder）。选刊不再是拍脑袋或退稿后临时抱佛脚，而是一次显式、可复盘的匹配决策。
>
> 解决的问题：PaperForge 此前假设 target journal 已定（paper_state 里直接填），没有任何步骤负责"怎么定"。真实流程里选刊错位是最贵的失败——投错刊等一轮审稿周期才知道，退稿后又在情绪里仓促选下一家。实证案例：2026-06 稿件被《图书情报工作》退稿后，重选目标刊（《情报理论与实践》）的全部分析是临时手工做的，未沉淀方法。
>
> 与其他文件的分工：`venue_profiles/<刊名>.md` 存单刊事实（本文件的**数据源**）；`genre_landscape_scan` 判断形态在各刊有没有先例（本文件的**输入之一**）；本文件只做**横向比较、分层与排序**，单刊的适配判断以该刊 profile 为准，不越权。
>
> 设计来源：Stanford REAP / CoPaper.AI `awesome-journal-skills` 的 `shared-resources/journal-selection/journal-match.md`。吸收其五信号画像 → 五维打分 → 三档分层 → 重投阶梯的方法论；候选集不用它的 185 刊索引，用 PaperForge 自己的 `venue_profiles/`（不够时现场建档）。

## 触发时机

- 论文有了结果/初稿，target journal 还没定（正常流程：Step 4.55 形态扫描之后、4.6 范例学习之前）
- **刚被退稿**，需要最优的下一家（走本文件第 6 节的重投阶梯）
- 审稿人/编辑说 not a fit，需要重新想 scope

## 1 · 论文画像（五个信号）

| 信号 | 本文取值 | 说明 |
|---|---|---|
| 学科 + 子领域 | | 决定候选集从哪些刊里出 |
| 方法/设计 | | 质性访谈 / 问卷-SEM / 实验 / 混合 / 理论 / 综述——质性论文不投只收实证的刊 |
| 贡献类型 | | 新事实 / 新机制 / 新方法 / 新理论 / 新概念框架 / 政策评估——不同刊奖励的类型不同 |
| 情境/数据/区域 | | 数据可得性、单案例还是多机构、中国情境是否需要显式论证 |
| 野心/强度 | | 结论的一般性、证据的干净程度——**诚实评估**，决定 reach 与 safe 的边界 |

## 2 · 候选集

从 `venue_profiles/` 里按学科 + 文章类型偏好过滤；相邻学科也纳入（如 LIS 论文可同时看情报类与教育类）。候选刊没有 profile 的，先按 `venue_profile_template` 快速建档（至少填元信息 + 定位栏目 + 审稿决策三节），**不允许凭印象比较一本没有档案的刊**。

## 3 · 五维评分（用于排序分档，不造精确分数）

| 维度 | 读什么 | 高分 = |
|---|---|---|
| 适配 Fit | profile 的定位与栏目偏好 + 形态/壳偏好 | 研究问题与贡献类型正落在该刊常发范围 |
| 录用可能 | profile 的录用率印象 + 常见退稿触发点，对照本文强度 | 以本文的证据强度，过稿现实 |
| 周期 | profile 的审稿周期 | 首轮决定快（毕业/考核钟摆下权重放大） |
| 成本/政策 | 版面费、数据政策、退稿后可否重投 | 可负担、可合规 |
| 读者面 | 该刊读者构成 | 触达这项贡献真正需要的读者 |

五维**综合成排序与分档判断**，不要编一个加权总分——录用可能这一维本身就高度不确定，假精度只会掩盖判断。

## 4 · 三档清单（每档 2–3 本，各带一行理由）

| 档 | 刊 | 一行理由 + 关键事实（周期/退稿点/字数） |
|---|---|---|
| Reach（够得着的高线） | | |
| Match（主攻目标） | | |
| Safe（保底且体面） | | |

只给 reach 是浪费时间线，只给 safe 是贱卖论文——三档都要有。

## 5 · 投递顺序与重投阶梯（投第一家之前就写好）

```
V_top → 若退稿 →（需要改什么）→ V_next → 若退稿 →（需要改什么）→ V_safe
```

每一级注明降级时**最少需要的重构**（压字数 / 换栏目 / 补稳健性 / 换政策框架 / 换学科锚定词汇）。阶梯在投稿前锁定，退稿当天按阶梯执行，不在情绪里重新选刊。

## 6 · 退稿后重跑规则

- 案头退（desk reject）→ 通常是 fit/形态问题，直接下一级，配合 `genre_landscape_scan` 复核形态
- 外审退（referee reject）→ 先按审稿意见修掉决定性硬伤（回到 claim_evidence / robustness），**再**下投，阶梯级别可以不降
- 同一家刊退稿后可否重投，以该刊 profile 的「退稿后同稿可否重投」字段为准

## 硬规则

1. **易变事实现读现用**：周期 / 录用率 / 字数 / 版面费一律从 venue profile 读（注意 `⚠️待复核` 标记），不从记忆里引
2. **单刊适配判断以该刊 profile 为权威**，本文件只做横向分层与排序
3. **对胜算诚实**：不把论文吹进它够不着的 reach，也不埋掉现实的 match
4. **覆盖诚实**：合理候选刊若无 profile 且来不及建档，明说，不硬塞进清单
