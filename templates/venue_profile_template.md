# Venue Profile · 期刊档案

> 用途：把 `exemplar_learning_dossier` / `genre_landscape_scan` 的**临时产出**沉淀成**跨论文复用、可缓存**的目标刊档案。一本刊建一次，以后每篇投这本刊都直接调用。
>
> 解决的问题：PaperForge 现有的 venue 学习是"每篇论文从零现学"，学完不沉淀。结果同一本刊投三次、学三次，且格式规范（标点、参考文献体例、摘要结构）反复踩同样的坑。
>
> 与 `exemplar_learning_dossier` 的分工：dossier 学的是**这一篇怎么写**（针对当前选题的范例）；venue profile 存的是**这本刊长期不变的硬规范与隐性偏好**（结构化摘要格式、引用体例、字数、栏目、形态偏好）。dossier 是一次性的，profile 是常驻资产。
>
> 设计来源：Stanford REAP / CoPaper.AI 的 `awesome-journal-skills`（519+ 刊的按刊技能包，Journal + Journal-Skills 配对组织）。本文件吸收其"持久化按刊知识"的架构，但**只建 PaperForge 实际投递的刊**，不照搬其英文大刊内容包。

## 实证背书

- venue mismatch（含格式/形态/引用体例错位）是中文 LIS 与教育类期刊退稿的高频低级原因。
- 退稿案例（2026-06，《图书情报工作》）：审稿意见第 8 条专门点名"摘要标点等低级错误、格式混乱"——这类问题本可由常驻 venue profile + format gate 一次性拦截。

## 维护规则

1. 一本目标刊一个文件：`venue_profiles/<刊名>.md`
2. 所有"硬规范"字段必须标注**核验来源链接 + 核验日期**；超过 12 个月未核验的字段标记 `⚠️待复核`
3. 拿不准的字段写 `以官网最新稿约为准`，**不要编**
4. 每次实际投递这本刊后，把新观察（审稿周期、退修偏好、被点名的问题）追加到「实战记录」
5. 本文件喂给 `venue_format_standards`（格式 gate）与 `exemplar_learning_dossier`（风格学习）
