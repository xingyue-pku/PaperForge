# Genre / Shell Landscape Scan

> 用途：在 exemplar learning 之前，**先扫描 target field 同类型文章的"壳形态"光谱**，确认你想写的形态在该领域有 precedent。若无 precedent，回头调整主题界定 / venue 选择 / 壳类型，**避免写出一篇"内核正确但任何刊都不发"的论文**。
>
> 解决的问题：venue mismatch 的根因往往不是文字风格（exemplar_learning_dossier 解决文字风格），而是**形态/壳错位**——你写的是 X 形态（如纯 problematization 反思综述），但 venue 只接收 Y 形态（如范式重塑型 / 公认模型骨架型 / 三段式归纳型）。
>
> 与 exemplar_learning_dossier 的差异：exemplar dossier 是 1 个 venue 深挖 2-3 篇；本文件是 5-9 个 venue 广扫 ~30 篇，重点不是文字风格而是**形态归类**。

## 实证背书

- 文献综述方法学（Grant & Booth 2009 HILJ）系统识别出 14 种综述类型，每种被不同 venue 接收的偏好不同。**忽略形态光谱差异 = 写"理论正确但无人发"的论文**。
- 案例（2026-05，同行评议判断机制综述）：稿件按 problematization-informed review（Alvesson & Sandberg 2020）方法写完后，跨 9 本中文 LIS 核心期刊扫描发现该形态在 2025-2026 年**零纯样本**——但"范式重塑型 / 视角驱动型 / 全评价理论壳"等近亲形态被广泛接受。无此扫描则稿件无家可投。

## 何时使用

触发条件（任一满足即应运行）：

1. **形态非标**：稿件方法学非主流（problematization / hermeneutic / critical synthesis / theoretical position / 等）
2. **首投目标 exemplar 稀缺**：Step 4.6 exemplar_learning_dossier 在目标 venue 找不到 3 篇 strong exemplar
3. **形态自我怀疑**：作者已经在写但"觉得这个形态没看见过同行用"
4. **拒稿信号**：审稿意见出现"interesting but not the form we publish here"或"out of scope for our journal type"
5. **跨学科投稿**：从一个学科 venue 转投另一个学科 venue，需重新对齐形态

## Procedure

### Step 1 · 定义扫描范围

- **文章类型 filter**：综述 / 实证 / 方法论 / 理论立场 / 综合等。**只扫与你稿件同类型的文章**，否则 noise 大
- **时间窗**：12-18 个月（足够看趋势，但反映当下编辑偏好）
- **Venue set**：target venue + 5-8 个同档 peer venues
  - 中文 LIS：G25 北大核心 18 本（可选其中 6-9 本最相关）
  - 中文管理学：南大 CSSCI 管理学领域 10-15 本
  - 英文 IS：MIS Quarterly / ISR / JMIS / EJIS / JAIS / DSS / I&M / IJIM 等
  - 英文 CS：ACM TOPLAS / IEEE TKDE / ACL / EMNLP / ICLR / NeurIPS 等

### Step 2 · 每个 venue 的 mini-audit

每个 venue 抓：

| 维度 | 内容 |
|---|---|
| 该 venue 在时间窗内总发文量 | ~X 篇 |
| 与你稿件同类型的文章数 | ~Y 篇（占 Z%） |
| 是否设固定栏目（综述 / Review / 等）| ✓ / ✗ |
| 该类型发文趋势 | 上升 / 平稳 / 下降 |

### Step 3 · 每个 venue 抓 3-5 篇样本卡片

每篇卡片：

```
#### 卡片 V?-?
- 题目（全文）：
- 摘要"方法"段（原文）：
- 摘要"产出"段（原文）：
- 主导壳类型（选一）：
  - 公认模型骨架（PRISMA / OAIS / Bornmann / UTAUT / TOE / 等）
  - 三段式归纳（A/B/C 三剖面）
  - 视角驱动（"X 视角下…"）
  - 范式重塑（"从 X 到 Y"+"范式重塑路径"）
  - 政策周期 + 前瞻（"X 回顾 / Y 展望"）
  - 文献计量驱动（CiteSpace / BERTopic / 等）
  - 本土理论框架（如"全评价"/"主文献"/等中文学界本土理论）
  - 混合
- 产出形态（选一/多）：
  - 新分析框架
  - 应用场景分类
  - 演进脉络
  - 研究议程
  - 问题反思 + 重塑路径
  - 测度/识别模型
  - 其他：____
- 与本文形态可比性（1-5）：
- 是否可作 anchor（✓ / ✗）：
- 笔记：
```

### Step 5 · 主题 / 壳 / venue 重新定位决策

回答 4 个问题：

1. **当前稿件形态**：你写的是哪类壳？
2. **该壳在 target field 的分布**：占比 / 哪些 venue 接收 / 是否在上升 / 下降
3. **如果当前壳分布稀薄**：选其一处置
   - **Re-shell**：内核保持，改外壳（参考 anchor 文章重组结构）
   - **Re-frame**：缩小或拓展主题，对接某个高接收度壳
   - **Re-venue**：换 venue（你当前壳的接收度更高的 venue）
   - **Re-genre**：彻底改文章类型（如 review → empirical）
4. **决策固化**：
   - 选定的壳：____
   - 选定的 venue：____
   - Anchor 文章（≥ 1 篇）：____
   - 预估改造工作量：____

### Step 6 · 产出与下游对接

完成本扫描后产出：

- `genre_landscape_scan.md` — 本扫描报告（含 Step 1-5）
- 更新 `question_lock.md` — 若 Step 5 触发 Re-frame
- 更新 `motivation_lock.md` — 若 Step 5 触发 Re-frame 或 Re-shell
- 更新 `notes/paper_state.json` — 添加 `selected_shell` / `anchor_articles` / `landscape_scan_date` 字段
- 触发 Step 4.6 exemplar_learning_dossier 重做（如 venue 改变）

## 不允许出现的"借口"

- "我目标 venue 已经定了，没必要扫别的 venue"——本文件不是为了换 venue，是为了用别 venue 数据看清你当前 venue 的形态偏好
- "我熟悉这个领域所有期刊"——熟悉 ≠ audit。形态归类需要结构化记录
- "我已经写完了，重组太麻烦"——形态错位的稿件被拒后**重组成本 << 多次投稿失败的累积成本**
- "我自创框架在国际期刊上有 precedent"——国际 vs. 中文期刊的接受度规则不同。**只看 target field 的近 18 个月数据**

## 输出约束

1. 每个样本卡片**必须从期刊官网 / CNKI / 主流数据库实际抓取**——不要瞎编题目
2. 同类型发文比例**给出粗略数字**（"约 X 篇/期" 或 "占总发文 ~Y%"）
3. 时间窗超出 18 个月的样本**不计入主分析**（但可作历史参考）
4. 若某 venue 该类型发文为 0：明确写"零发文"，不要补其他类型凑数
