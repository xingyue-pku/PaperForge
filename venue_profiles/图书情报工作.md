## 2 · 定位与栏目偏好

- **偏好选题方向**：图情理论与方法、信息行为、知识组织、数据治理、智慧服务、AI 与科研/学术、信息素养、科学计量。
- **文章类型偏好**：实证与方法类为主，理论建构要求高；纯综述需有强问题定位。
- **本刊明显冷落**：缺乏理论贡献的应用描述、同题扎堆的"风险清单+原则倡议"。
- **形态偏好**：偏"问题驱动 + 可操作框架/模型"的实证；要求系统性、理论建构科学性（见退稿意见第 7 条）。

## 3 · 硬性格式规范 ⭐

| 维度 | 要求 | 备注 |
|---|---|---|
| 正文字数 | 约 8000–12000 字 | ⚠️以官网为准 |
| 摘要结构 | **结构化**：`[目的/意义]` `[方法/过程]` `[结果/结论]` | 已由本刊已发文确认（含本团队稿件） |
| 摘要字数 | ≈ 200–300 字 | ⚠️ |
| 中英文摘要 | 都要，语义对应 | |
| 关键词 | 中英文对应，3–8 个 | ⚠️核对区间 |
| 中图分类号 | 要（《中图法》），本团队稿用 G251 | |
| 参考文献体例 | GB/T 7714-2015 | |
| 文中引用标注 | 顺序编码，上标方括号 [1] | |
| 标题编号 | 阿拉伯数字 `1 / 1.1 / 1.1.1`，附英文小标题 | 本刊惯例双语小标题 |
| 双语要求 | 题名 + 摘要 + 关键词均需英文 | |
| 作者信息 | 单位、城市、邮编、第一/通讯作者简介、基金 | |
| 图表 | 编号 + 中英文双语题注 | |

## 4 · 引用与文献习惯

- 文献数量：通常 30+ 条；近 5 年占比高。
- 中英文引用混合，重视国际前沿对接。

## 5 · 风格画像

- 学术严谨、术语密度中高；贡献句多显式列出；强调理论与方法贡献。

## 6 · 审稿与决策

| 字段 | 内容 |
|---|---|
| 审稿流程 | 编辑部初审 → 双外审 → 终审 |
| 审稿周期 | 约 1–3 个月（本团队实投经验：初审 5.25→6.1，外审 6.1→6.16，终审退稿 6.20） |
| **退稿后同稿可否重投** | **否。** 本团队实投经验为终审退稿（reject，非 major revision），编辑部与外审留档，同稿不应原样重投 |
| 常见退稿触发点 | 理论建构科学性不足、问题不聚焦、同题扎堆、格式低级错误 |

## 7 · 投稿前适配清单

- [ ] 摘要三段标签齐全、无多余标点
- [ ] G 类中图分类号、双语三要素齐全
- [ ] GB/T 7714-2015 + 上标方括号
- [ ] 标题阿拉伯编号 + 英文小标题
- [ ] 选题有明确理论贡献、非风险清单堆砌
