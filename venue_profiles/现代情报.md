## 2 · 定位与栏目偏好

- **偏好选题**：信息行为、用户研究、知识服务、数据治理、AI 与情报/科研、信息素养、舆情。**对 GenAI + 质性研究接纳度高。**
- **文章类型偏好**：实证（含质性）友好；审稿相对较快。
- **形态偏好**：问题驱动实证、调查/访谈类常见。
- **定位判断**：从《图书情报工作》平移下来最顺的落点，性价比高（见 `修改指引.html` 期刊策略）。

## 3 · 硬性格式规范 ⭐

| 维度 | 要求 | 备注 |
|---|---|---|
| 正文字数 | **8000 字以上，原则上不设上限** | 官网须知 |
| 摘要结构 | 含研究的**目的、方法、结果、结论**；中英文对应 | |
| 摘要字数 | **200 字左右** | |
| 关键词 | **3–8 个**，中英文对应 | |
| 中图分类号 | 《中图法》第五版；**跨学科研究需两个分类号** | |
| 参考文献体例 | GB/T 7714；**随文标注**；**≥ 7 条** | 官网写 2005 版，投稿前确认是否已更新为 2015 |
| 双语要求 | 题名 + 摘要 + 关键词需英文 | |
| 稿件结构顺序 | 中文标题→作者→单位/城市/邮编→中文摘要/关键词/分类号→英文标题→英文摘要/关键词→正文→基金项目→通讯作者→作者简介→参考文献→**作者贡献说明**→**支撑数据** | 官网须知 |
| 作者信息 | 第一作者简介（姓名、性别、出生年、职务职称、研究方向、发表情况）；基金列名称+编号 | |

## 4 · 引用与文献习惯

- 文献 ≥ 7 条（实际质性实证多在 25–40 条）；中英文混合。

## 5 · 风格画像

- 实证叙事清晰，方法节可操作；术语密度中等；接受质性长引文。

## 6 · 审稿与决策

| 字段 | 内容 |
|---|---|
| 审稿周期 | 相对较快（业内印象） |
| 录用率印象 | 高于《图书情报工作》同档核心，改投性价比高 |
| 退稿后重投 | 视情况，以编辑部回复为准 |
